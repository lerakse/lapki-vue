# Лапки — интерфейс на Vue.js (ЛР № 4)

Интерфейс мобильного приложения «Лапки» (адаптация и сопровождение животных из приютов), реализованный на Vue 3 (Options API) по UI-компонентам из ЛР № 1.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте адрес из терминала (обычно http://localhost:5173).


## Поток данных

- `App` хранит массив `pets` в `data()` и передаёт его в `PetList` через props, а `PetList` передаёт каждого питомца в `PetCard`.
- `PetCard` по клику на сердечко генерирует событие `toggle-favorite`, по кнопке «Заметки волонтёров» – событие `select`. `App` добавляет питомца в избранное или убирает из него, а счётчик в шапке (вычисляемое свойство `favoritesCount`) пересчитывается автоматически.
- `CommentSection` получает имя питомца и его заметки через props, а при отправке формы генерирует событие `add-comment`. `App` добавляет заметку в массив, и список обновляется автоматически.

Внешние библиотеки управления состоянием (Vuex, Pinia) не используются.
